# Roadmap

本文件记录已完成基线、近期计划与已知问题。优先级用 P0（发布阻断）/ P1（重要）/ P2（改进）标注；编号 A* 来自架构评审，R* 来自安全评审，B* 来自验收评审。

## 已完成（v0.1.0）

- [x] 单帧多目标跟踪：每目标一个 OpenCV 跟踪器，IoU 关联维持 ID
- [x] ID 生命周期：丢失容忍 `max_missing` 帧、超时销毁、新目标自动分配
- [x] 轨迹绘制（带衰减）与 CSV 导出（原子写、注入转义、`--append`）
- [x] 摄像头 / 视频输入、录像输出、无显示运行
- [x] 鼠标新增 / 删除目标、暂停、重置、截图、帮助
- [x] `csrt` / `kcf` / `mil` / `mosse` 后端兼容链（现代 API → legacy → class.create）
- [x] 严格配置校验、`--max-tracks`、检测器异常容错、同帧去重阈值统一
- [x] 安全硬化：拒绝符号链接写入、CSV 公式注入（含 BOM/零宽绕过）、配置体积与字段上界、空源退出码
- [x] 279 个 pytest 用例、ruff 检查、CI、打包校验、Issue/PR 模板、文档

## v0.2 — 正确性与兼容性（P0/P1）

- [ ] **A1** CSV `frame` 语义：改用会话全局帧号写 CSV（`manager.frame_index` 仅作 UI），或 `r` 时轮转 CSV / 快照目录 — P0
- [ ] **A5** `TrackManager._refresh` 加异常保护：重新 `init` 失败时 `misses += 1` 转 `LOST`，不让异常穿出 `step` — P1
- [ ] **B/GUI** 真实摄像头与 GUI 手测清单（框选、缩放、窗口关闭、暂停新增） — P1
- [ ] **A3** CI 版本矩阵扩展：OpenCV 4.5.1 / 4.10 / 最新 × Python 3.9–3.12，README 维护“已验证”表 — P1
- [ ] **A8** 明确 `detection_interval` 语义（首个检测帧），或在首帧就检测 — P2
- [ ] `matched` 索引对语义补文档与便捷映射（`track_id` 视图） — P2
- [ ] 摄像头时间戳漂移：允许随帧传入时间戳，`--loop` 后与真实时间对齐 — P2

## v0.3 — 扩展方向（P2）

- [ ] **A2 / R6** YOLO 检测周期刷新接线到 config / CLI：`detector: {backend: yolo, model: ..., interval: N}`，默认关闭；模型路径限制在本地、默认不自动下载权重，并在文档中标明 `.pt` 的代码执行风险
- [ ] 性能：CSV 批量 flush、跳帧/降采样、避免整帧 copy；给出基准脚本与数据
- [ ] 机器人 / ROS 复用示例：事件化输出、检测与跟踪异步解耦
- [ ] 可选卡尔曼滤波 / 运动模型，改善快速运动下的 IoU 关联
- [ ] 可选 ReID 或颜色直方图特征，降低交叉换 ID
- [ ] 纯脚手架模式：若仓库仅作教学骨架，可裁剪 `src/mot` 为带 TODO 的模块桩（当前保留完整参考实现）
